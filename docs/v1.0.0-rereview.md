## 逐项裁决

### P0-1 certbot 续期不重载 nginx —— 通过
`bootstrap.sh` 新增 `install_renewal_reload_hook`：无条件写入 `/etc/letsencrypt/renewal-hooks/deploy/10-reload-nginx.sh`（`nginx -t && systemctl reload nginx`），目录钩子对存量证书同样生效，正中终审指出的「存量服务器已入证书跳过分支」要害。certbot 未装时本就整体跳过 HTTPS、装好重跑必装钩子，闭环成立。`deploy/README.md` §8 补了手工装法与验证步骤。

### P0-2 `javascript:` 存储型 XSS —— 通过
双层防线：入库层 `feeds.py` 新增 `is_web_url`（http/https 白名单，`parse_feed` 丢弃非法 link）；渲染层 `pages.py` 新增 `safe_url` Jinja 过滤器，`home.html` / `article.html` / `email.html` 全部 5 处动态 href/src 均已接入（含终审未要求的 image.src，加分）。新增 `test_render_safety.py` 8 项测试覆盖两层 + 端到端恶意 URL 渲染 + autoescape，全绿。模板残留动态 URL 仅 `site_url`（运维配置，非外部数据），安全。

### P0-3 gh 全权限 token 驻留服务器 —— 通过
`deploy-all.ps1` 删除 `gh auth token` 管道，改为 `ND_GHCR_TOKEN` 环境变量或隐藏输入的 read:packages 只读 PAT；token 走 stdin 不上 argv，登录后置 null，`config.json` 收紧 600。全库扫描无 `gh auth token` 残留（仅注释警示）。旧 token 轮换归入 P0-8 操作项。

### P0-4 部署覆写生产 .env —— 通过
改为 `.env.incoming` 暂存 9 个受管键 → bootstrap 用 awk 逐键 upsert（其余行与注释保留、新键追加、值含 `=` 安全、合并后删 incoming、保 root:600）。**已实证**：沙箱模拟含注释/运维自加键/`=` 值的合并，行为全部正确。语义自洽：本地 `.env.local` 是受管键的部署时 source of truth（轮换密钥正靠此下发），面板热切换在两次部署之间生效，档案本体存 `providers.json` 部署不碰。

### P0-5 回滚链空（digest + DEPLOYED.log）—— 通过
`record_deployed()` 在 pull 后把 tag 与实际解析出的 worker/web RepoDigests 追加写入 `backups/DEPLOYED.log`（终审时全库 0 处写入，现已落地）。新增 `ND_WORKER_DIGEST`/`ND_WEB_DIGEST` 按 digest 部署通道（格式校验 + `@sha256:` 渲染），并加反降级保险：线上 compose 已固定 digest 而本次未给全 digest 时拒绝执行（`ND_ALLOW_TAG_DOWNGRADE=1` 显式放行）。回滚动作 = 从台账取上一条 digest 重跑，链路成立。

### P0-6 SMTP TLS 不校验证书 —— 通过
`mailer.py` 建立模块级 `ssl.create_default_context()`（CERT_REQUIRED + check_hostname），465 隐式 SSL 传构造器、STARTTLS 传 `starttls(context=...)`，两条路径全覆盖；`test_email.py` 两处断言上下文必须传入。

### P0-7 版本号散落 / tag 纪律 —— 通过
`deploy-all.ps1` 与 `server-push.ps1` 版本一律从 `__init__.py` 正则单源推导（硬编码删除），经 `ND_VERSION` 传给 bootstrap；新增 tag 预检：本地 tag 必须存在、远端同名 tag 指向不同提交即拒绝（禁移已发布 tag，正中 rc3/rc4 事故根因）；bootstrap 部署后核对镜像 OCI version label 与 TAG。CI 侧 tag==__version__ 门禁原已在位。bootstrap/install.sh 默认值仅作独立运行兜底，编排链路必被覆盖。

## 遗留问题（不拦发版，需记录）
1. **注释失实**：`bootstrap.sh` digest 段注释称「deploy-all.ps1 在推送后解析 digest 并传入」——deploy-all 实际未实现 digest 解析（当前按 README §4 手工固定 + 台账查询的语义运行）。改一行注释或后续把自动解析补上，二选一。
2. **README §8 dry-run 说法不准**：`certbot renew --dry-run` 默认**不执行** deploy 钩子（certbot 文档明确 renewal-hooks/deploy 在 dry-run 时跳过），「输出里应能看到 reload 信息」不成立。验证钩子应直接执行钩子脚本本身或加 `--run-deploy-hooks`。
3. **行为须知（非缺陷）**：每次部署会把三个 `TRANSLATION_*` 受管键还原为本地 `.env.local` 值——面板热切换的供应商会被重置，需在面板重新启用（档案与密钥不丢失）。建议在 OPERATIONS 记一句。
4. 终审非阻塞清单（action SHA 固定、OPERATIONS 补章节、06:30 笔误等）本轮未动，维持发版后跟进。
